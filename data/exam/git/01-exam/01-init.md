title: ~/profile をGitで管理できるようにして（git init）、index.html を「最初のコミット」というメッセージでコミットしてください。
required: true
example:
  - 'git init'
  - 'git add index.html'
  - 'git commit -m "最初のコミット"'
feedback: git init でリポジトリを作り、git add index.html でステージに追加してから git commit -m "最初のコミット" を実行してください。
