title: ~/team のリモート（origin）には、チームのメンバーが新しいコミットを追加しています。手元の main をリモートの最新の状態にしてから、その main をもとに feature という名前のブランチを作り、feature に切り替えてください。
required: true
example:
  - 'git pull'
  - 'git switch -c feature'
feedback: 手元の main がリモートの最新と同じで、最新の main から作った feature ブランチにいる状態にしてください。
