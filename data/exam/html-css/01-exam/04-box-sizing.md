title: box-sizing が border-box のとき、width で指定した値に含まれる範囲はどれですか？
required: true
choices:
  - コンテンツだけで、padding と border は含まない
  - コンテンツと padding で、border は含まない
  - コンテンツと padding と border
  - コンテンツと padding と border と margin
answers:
  - コンテンツと padding と border
feedback: border-box では、width の中に padding と border も含まれます。margin は含まれません。
