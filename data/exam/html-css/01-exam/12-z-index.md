title: 重なった要素の前後（どちらが上に見えるか）を変えるために使うプロパティはどれですか？
required: true
choices:
  - z-index（その要素の position が static 以外であること）
  - font-size
  - text-align
  - overflow
answers:
  - z-index（その要素の position が static 以外であること）
feedback: z-index は重なり順を変えます。効かせるには、position を relative や absolute など、static 以外にする必要があります。
