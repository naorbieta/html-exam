type: コード
title: flexbox を使い、メニューの項目（li）が横一列に並ぶようにCSSを書いてください。
language: css
required: true
example: |-
  .menu {
    display: flex;
  }
feedback: flexbox（display に flex または inline-flex）を指定し、項目が横に並ぶようにしてください。
---

用意されているHTMLの `.menu` に対して、flexbox で横並びにしてください。書き方が違っても、flex で同じ見た目になれば正解です。
