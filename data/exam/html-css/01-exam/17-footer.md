title: スクロールしても、フッターを画面の下端に残す指定として適切なものはどれですか？
required: true
choices:
  - "position: fixed; bottom: 0; width: 100%;"
  - "position: relative; bottom: 0;"
  - "display: flex;"
  - "float: left;"
answers:
  - "position: fixed; bottom: 0; width: 100%;"
feedback: 画面に対して固定するには position を fixed にし、bottom を 0 にして下端に置きます。relative ではスクロールすると一緒に動きます。
