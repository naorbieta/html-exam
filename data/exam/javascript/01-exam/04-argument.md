title: |-
  次のコードの '花子' のように、関数を呼び出すときに渡す値を何といいますか？
required: true
choices:
  - "引数"
  - "戻り値"
  - "変数名"
  - "配列"
answers:
  - "引数"
feedback: "関数に渡す値が引数、関数が return で返す値が戻り値です。"
---

```js
function greet(name) {
  console.log('こんにちは、' + name);
}

greet('花子');
```
