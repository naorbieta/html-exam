CSSの指定ができる場所は、３種類あります。
①htmlタグに直接指定をする
②htmlファイル内のどこかで指定をする
③cssファイルを作成し、反映させたいhtmlから呼び出す


この三つのパターンを、以下のhtml文を使用して指定してください。


<!DOCTYPE html>
<html>
<head></head>
<body>
    <p>この文字は18pxの半透明の赤色で、太文字で表示されています。</p>
</body>
</html>


【条件】
・pタグ内の説明通りのCSSを適用してください。
・opacityではなく、rgbaで指定してください
・太文字と赤色は、細かい指定はありません。
・css適用時に「必要な」コードは自由に追加してください。
・cssファイルの名前は「design.css」。階層は、同階層の「css」ディレクトリ内に置いてください。
・②の場所の指定はどこでもかまいません（極端におかしなところじゃなければ）
・③は、ファイル内容の記載は不要です。
