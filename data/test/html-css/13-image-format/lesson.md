【クイズ第13問】画像の種類
各画像形式の説明がされている番号を答えてください。


PNG
JPEG
BMP
GIF
WebP
SVG


①拡大・縮小をしても画質が劣化せず、容量も小さい。写真などの画像では容量が大きくなる。
ベクター画像なのでCSS上で画像データの数値を変えれば色やサイズの変更が可能。


②可逆圧縮。フルカラー写真などを劣化無しで圧縮できる。


③不可逆圧縮。フルカラーで圧縮率が高いので、写真などの圧縮に使われる。


④容量が小さく、アニメーションが表示できるが色数が256色と少ない。可逆圧縮。


⑤新しい画像形式。画像のサイズを小さくし、表示速度を早くできる。背景透過も可能。


⑥フルカラーを扱えるが、基本的に圧縮されない。
