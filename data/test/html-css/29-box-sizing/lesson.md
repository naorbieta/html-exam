CSS には 「box-sizing」という
プロパティがあります。

このプロパティは、
一番最初に、全体にかけることが多く、
普段のコーディングでは、あまり意識することがないかもしれません。

そこで、
今一度、このプロパティを設定することで
どのような表示になるのかを理解しましょう。
