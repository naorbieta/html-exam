CSSで色を指定するとき、

RGBで色を指定するのが
最もメジャーですが、

HSLというのでも色を指定することができます。
これは色の、ある3つの成分を数値やパーセントで指定する方法です。

例えばこんな感じで指定できます。

color: hsl(60, 100%, 80%);

人間の感覚に近い表現方法といわれ、

ちょっと色を明るくしたい、
ちょっと強い色にしたい、

などがやりやすいです。

さて、どの数値をいじると、どう色が変わるのか？
確認しましょう。
