if文やelse if文を組み合わせていけば、
たいていの条件分岐を書くことができます。

ただ、複数の条件をすべて満たすとき
という条件を書くときは下記のように書くこともできます:

if (A && B) {
// AとBどちらも条件を満たす
}


また、複数の条件のどれか1つでも満たしていればいいというときは、
このように書けます。

if (A || B) {
// AかBのどちらかを満たしていればよい
}


if文をたくさん組み合わせて…とするよりも、
これらを使えるときは使ったほうが、
シンプルで何の条件なのかが読みやすいです。


さて、問題です。
画像のような条件分岐を
一から書いてみましょう。

（①がスタートです。）
