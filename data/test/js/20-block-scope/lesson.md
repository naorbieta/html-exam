変数には、スコープという
変数の有効範囲があって、

変数を呼び出す場所によっては、
プログラムの結果が変わることがあるので注意が必要です。


スコープの例として、
例えば、if文を書いたときに、

if (n < 1) {
// ここに処理を書く
}

という感じで、
{} でコードを囲むことがありますが、

この、{}を
「ブロック」といい、

このブロックの中で
letやconstで、変数や定数を宣言すると、

そのブロックの中だけでしか、
変数や定数を呼び出せません。

ブロックの中が有効範囲なので、
これを、「ブロックスコープ」といいます。


それでは、問題です。
