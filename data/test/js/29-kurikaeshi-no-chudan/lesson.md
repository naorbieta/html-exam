繰り返し文は、ある条件が成立している間繰り返される処理です。

しかし、時には違う条件が成立したときに、
繰り返しを止めたい場合があります。

このような場合、break文を使うことで
繰り返しを途中で強制的に終了することができます。

例えば、

(窓の汚れが消えるまで) {
	拭く;
	if (拭いても拭いても消えない) {
		break;  // 続けても意味がないのでやめる
	}
}

といった具合です。

では、問題です。
下の画像を見てください。

1~10までの数値をランダムに生成して、
コンソールに表示することを10回繰り返しています。

「?」の部分にコードを記述して、
次のように動くプログラムにしてみましょう。

・1~10の好きな数字どれかを1つ指定して、
その数字が出たら、alertダイアログボックスに当たったことを表示して
繰り返しを終了する
・10回試行して、指定していた数字が出なかったときは、
alertダイアログボックスにハズレたことを表示。
