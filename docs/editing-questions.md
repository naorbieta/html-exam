# 問題の編集手順

## 選択問題を追加する

「設問」シートの空いている行に、次の6項目を入力します。

| 列 | 入力例 |
| --- | --- |
| 分野 | HTML・CSS・Web基礎 |
| レッスン番号 | 5 |
| 設問 | ulはどのようなリストに使いますか？ |
| 回答形式 | 単一選択 |
| 選択肢 | 順序のあるリスト〈セル内改行〉順序のないリスト〈セル内改行〉用語と説明のリスト |
| 正解 | 順序のないリスト |

入力後、アプリを開き直すと反映されます。選択肢は画面でランダムに並びます。正解は番号ではなく、選択肢の文言をそのまま入力します。「複数選択」では、正解も1つずつセル内改行で入力します。

新しいレッスンを作る場合は、先に「レッスン」シートへ分野・レッスン番号・レッスン名・導入文を入力します。同じ分野と番号を「設問」に入力すると、そのレッスンに属する設問になります。分野が違えば同じ番号を使えます。

## 記述問題を追加する

回答形式を「短文」または「長文」にし、「正解」に許容する答えを1行ずつ入力します。前後の空白・全角と半角・英字の大文字と小文字の違いは無視します。選択肢は空欄にします。

この方法は値や名称など、答えを列挙できる設問に使います。説明文の意味を自動で読み取る採点には使いません。

## コード問題を追加する

回答形式を「コード」にし、必要なら「初期コード」に編集を始めるコードを入力します。採点方法などの任意列は、シート上部の「＋」で開きます。

コンソールへ10を出力する問題なら、次のように入力します。

| 列 | 入力例 |
| --- | --- |
| 設問 | 8と2の合計をコンソールに出力してください。 |
| 回答形式 | コード |
| 正解 | 10 |
| 初期コード | console.log(); |
| 言語 | js |
| 採点方法 | コンソール出力 |
| 解答例 | console.log(8 + 2); |

出力が複数ある場合は、正解セルに出力順で1行ずつ書きます。

動作を検証する場合は、採点方法を「JavaScript実行」か「HTML・CSS表示」にし、「採点コード」に検証するJavaScriptを書きます。たとえばJavaScriptの出力は `h.assert(h.logs.length === 2, '2回出力してください。');`、CSSの色は `h.assert(h.css('p').color === 'rgb(255, 0, 0)', '文字色を確認してください。');` のように検証できます。CSSだけを解答する問題は「参照HTML」に描画するHTMLを入力します。

既存の「登録済み」は、複数入力での動作確認や前問からの引き継ぎなどを含む採点ルールです。「採点ルール」列の値で `src/grading-rules.json` の定義を参照します。独自の複雑な採点を新設する場合は、この定義と採点プログラムを編集し、再ビルド・GASの更新が必要です。

## 任意項目と並べ替え

ファイルを選ぶ問題は、回答形式を「ファイル」にし、「正解」に `.js` のような拡張子を入力します。ファイルの中身は空でも採点できます。

「補足」「設問の説明」「不正解時のメッセージ」「ヒント」は必要な場合に入力します。「解答例」はコードや登録済みの採点で使います。通常の記述・選択問題は「正解」から自動生成するため、同じ内容を二重に入力しません。

「設問番号」があれば番号順、空欄ならそのレッスン内の行順になります。既存の途中へ入れる場合は任意列を開き、同じレッスン内で重複しない番号を付けます。行を削除すると、その設問はアプリの出題から外れます。過去の回答記録は削除しません。

「設問ID」「レッスンID」はGASが空欄に自動入力します。既存のIDは変更しません。新規行は空行から作るか、入力する列だけをコピーします。行全体を複製した場合は、複製先のIDを空にします。IDを保った行の並べ替えは回答との対応に影響しません。

## CSVから取り込む

`data/lessons.csv` を「レッスン」、`data/questions.csv` を「設問」に取り込みます。Googleスプレッドシートのインポート設定では、テキストの数値・日付・数式への変換をオフにします。セル内改行やコードをそのまま保持できます。CSVファイルを直接編集する場合、改行・カンマ・引用符を含むセルはCSVの引用ルールに従います。

列は見出し名で読み取るため並べ替えられます。列名は変更しません。入力に不足や矛盾があれば、アプリの読み込み時にシート名・行番号・修正する項目を表示します。

参考画像は「レッスン」の「参考画像」に `images/example.png` のようなパスを1行ずつ入力し、「画像の説明」も同じ順で入力します。新しい画像ファイルはプロジェクトのimagesフォルダへ追加し、再ビルド・GASの更新が必要です。
